Data sources

Supports GeoJSON, zipped Shapefile, GeoPackage (.gpkg), and GeoTIFF (.tif). Drag a file onto the map to load it. GeoTIFFs are only placed correctly if their embedded CRS is WGS84 (EPSG:4326) — others aren't reprojected.

Geoprocessing

Project

Saves every layer's geometry, symbology, and the current basemap/view to a single .webgis.json file you keep. Opening one replaces the current workspace.

Export & output

GeoTIFF export is a georeferenced raster (image + world file) using a linear WGS84 tiepoint from the current view — accurate for small/moderate extents, not a full reprojection. Opens directly in QGIS.

PDF export is a cartographic map sheet (title, coordinates, scale). It is not a geospatially-embedded GeoPDF — that format needs server-side tooling to produce reliably. To export a specific layer's vector data, use the download icon on that layer in the Layers tab.
